## Getting Started

### Prerequisites

- A C++ compiler such as GCC (`g++`), Clang, or MSVC.
- A code editor or IDE of your choice.

### Clone the Repository

```bash
git clone https://github.com/naba93980/cpp.git
cd cpp
```

### Compile and Run

Navigate to the folder containing the program you want to run, then compile the source file:

```bash
g++ filename.cpp -o program
./program
```

On Windows, run the generated executable:

```bash
program.exe
```

Replace `filename.cpp` with the actual source file name. Each program can be compiled and executed independently, provided it doesn't depend on other source files.
